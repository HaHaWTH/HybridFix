## System properties

These system properties can be set when you start your server, 
allowing for the configuration of various settings.

## List of system properties

### `hybridfix.asm.debug.export`

- default: `unset`
- description: Enables class bytecode exporting of ASM Patcher.

### `hybridfix.command.eraseentity.force`

- default: `unset`
- description: Enables force erasing of entities, enhances the erase entity command.

### `hybridfix.hook.residence.customRightClickKey`

- default: `Global.CustomRightClick`
- description: The custom right click config path to use for Residence.

### `hybridfix.hook.residence.customBothClickKey`

- default: `Global.CustomBothClick`
- description: The custom both click config path to use for Residence.

### `hybridfix.hook.residence.purgeUnavailableMaterials`

- default: `unset`
- description: Enables purging of unavailable materials for Residence.

### `hybridfix.debug.health.not_a_number`

- default: `unset`
- description: Enables debugging of setting NaN health, prints stack traces.

### `hybridfix.thaumcraft.forceDisableFluxRiftGrief`

- default: `unset`
- description: Prevents Flux Rift of Thaumcraft from breaking blocks.

### `hybridfix.removeReflectionFilter`

- default: `unset`
- description: Removes the reflection filter, allowing for reflection of private methods.
